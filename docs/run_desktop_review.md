# تشغيل مراجعة المالك على سطح المكتب

دليل لتشغيل التطبيق ومراجعة الـ 48 ربطًا مقترحًا **بدون تعديل ملفات JSON يدويًا**.

## المتصفح الموصى به

| البند | التوصية |
|-------|---------|
| المتصفح | **Google Chrome** أو **Microsoft Edge** |
| الوضع | نافذة **ملء الشاشة** على سطح المكتب |
| تجنّب | نافذة المعاينة الصغيرة داخل Cursor للمراجعة الكاملة لـ 48 عنصرًا |

---

## التشغيل من Cursor (أو الطرفية)

### 1. تثبيت الاعتماديات (مرة واحدة)

```bash
cd /path/to/Arabic-Watch
npm install
```

### 2. تشغيل خادم التطوير

```bash
npm run dev
```

الخادم يعمل عادة على: **http://localhost:3000**

### 3. فتح التطبيق في Chrome أو Edge

1. افتح **Chrome** أو **Edge** (ليس معاينة Cursor فقط).
2. اذهب إلى: `http://localhost:3000/#admin-review`
3. أو من الصفحة الرئيسية انتقل إلى **لوحة المراجع**.

### 4. فتح مساحة مراجعة المالك

1. في شريط التبويبات اختر **مراجعة المالك**.
2. انتظر تحميل **48** عنصرًا.
3. راجع **لوحة تقدّم المراجعة** في الأعلى.

---

## سير العمل اليومي (بدون JSON يدوي)

1. اختر عنصرًا من القائمة اليسرى.
2. اقرأ **البيانات المقترحة** (للقراءة فقط).
3. املأ **قرار المالك** في القسم السفلي.
4. راقب **معاينة التحقق** بالعربية.
5. استخدم **التالي / السابق** أو `j` / `k`.
6. **حفظ محلي** (`s`) أو الاعتماد على الحفظ التلقائي.

### اختصارات لوحة المفاتيح

| مفتاح | إجراء |
|-------|-------|
| `j` | العنصر التالي |
| `k` | العنصر السابق |
| `/` | تركيز البحث |
| `s` | حفظ محلي |
| `Esc` | إخفاء/إظهار لوحة التفاصيل |

## النسخ الاحتياطي للقرارات

> **قرارات المراجعة محفوظة محليًا في هذا المتصفح. يرجى تصدير JSON بشكل دوري حتى لا تضيع القرارات.**

### تصدير JSON (موصى به بعد كل جلسة)

1. اضغط **⬇ تصدير JSON**.
2. أكّد في مربع الحوار أنك تفهم أن التصدير **لا يُطبَّق** المحتوى.
3. احفظ الملف `owner_review_decisions.json` في مكان آمن (سحابة، قرص خارجي).

### استيراد JSON (استعادة جلسة سابقة)

1. اضغط **⬆ استيراد JSON**.
2. اختر ملفًا مُصدَّرًا سابقًا بنفس البنية.

### تنزيل Revised Proposed Patch

1. اضغط **إنشاء Revised Proposed Patch**.
2. يُنزَّل `evidence_patch.all_batches.revised.proposed.json` — **للمراجعة فقط، لا يُدمج تلقائيًا**.
