# مصادر المحتوى الموصى بها

## النص القرآني
1. منصة مطوري مجمع الملك فهد لطباعة المصحف الشريف.
   - مناسبة للمحتوى المعتمد الرسمي.
   - راجع الترخيص وشروط الاستخدام قبل النشر التجاري.

2. Tanzil Quran Text.
   - نص قرآني موثوق ومتاح للتنزيل.
   - يجب الالتزام بعدم تغيير النص وبنسبة المصدر وفق الرخصة.

3. QPC Hafs Script via QUL / Tarteel.
   - مناسب لمن يريد نص حفص مطابقًا لخط مجمع الملك فهد.
   - تأكد من شروط الخط والترخيص قبل الاستخدام التجاري.

## APIs
1. Quran Foundation / Quran.com API.
   - مناسب للآيات، السور، الصوتيات، الترجمات، البحث، والتفسير.
   - الأفضل استخدامه من Backend وليس مباشرة من Frontend.

2. QuranEnc API.
   - مناسب للترجمات وبعض المحتوى التفسيري بلغات متعددة.

## التفاسير
لا تعتمد على نسخ عشوائية من الإنترنت.
المسار الأفضل:
- استخدم مصادر مرخصة أو APIs موثوقة.
- اعرض ملخصًا تعليميًا قصيرًا مع الإشارة للمصدر.
- احفظ رابط المصدر ورقم الآية واسم الكتاب.
- اعتمد مراجعة طالب علم/مختص قبل النشر.
