# Quran Story Universe — حزمة التحويل إلى منتج 10/10

## الحكم التنفيذي
الملف الحالي ممتاز كـ Prototype تفاعلي، لكنه يحتاج إلى إعادة بناء طبقة المحتوى والبيانات حتى يصبح تطبيقًا قرآنيًا موثوقًا.

## الهدف
تحويل المشروع من صفحة HTML تحتوي بيانات ثابتة داخل JavaScript إلى منصة قرآنية معرفية قائمة على:
- نص قرآني موثوق.
- آيات كاملة مرتبطة بالقصص.
- مصادر تفسير معتمدة ومصرّح باستخدامها.
- محرك بحث دلالي.
- شبكة علاقات قابلة للتوسع.
- مراجعة علمية قبل النشر.

## الأولويات
1. فصل البيانات عن الواجهة.
2. بناء قاعدة بيانات قصصية قرآنية.
3. إضافة نظام مصادر لكل معلومة.
4. جعل التفاسير مقتطفات مختصرة أو ملخصات مرخصة، مع الإحالة للمصدر.
5. منع أي إجابة عقدية أو تفسيرية غير موثقة.
6. تحويل الواجهة إلى Flutter أو React لاحقًا بعد تثبيت قاعدة المحتوى.

## المنتج النهائي المقترح
اسم المنتج: Quran Story Universe / أطلس القصص القرآني

الأقسام الأساسية:
- الصفحة الرئيسية.
- الكون الشبكي.
- Story Mode.
- المصحف الموضوعي.
- غرفة كل نبي أو شخصية.
- محرك البحث.
- مقارنة التفاسير.
- الخرائط والعلاقات.
- مسارات تعليمية.
- لوحة مراجعة علمية للمحتوى.

## ملاحظات مهمة
- لا تنشر التطبيق كمصدر تفسير مستقل قبل المراجعة العلمية.
- تجنب توليد تفسير جديد من الذكاء الاصطناعي دون ربطه بالمصادر.
- اجعل التطبيق يقول دائمًا: "هذا ملخص تعليمي لا يغني عن كتب التفسير المعتمدة".
