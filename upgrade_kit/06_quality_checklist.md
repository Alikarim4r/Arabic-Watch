# Quality Checklist

## المحتوى
- [ ] كل آية لها سورة ورقم آية.
- [ ] كل حدث مرتبط بآية أو أكثر.
- [ ] كل ملخص تفسير له مصدر.
- [ ] لا يظهر محتوى غير مراجع للمستخدم العام.
- [ ] يوجد تنبيه أن المحتوى تعليمي.

## الواجهة
- [ ] RTL كامل.
- [ ] تصميم موبايل ممتاز.
- [ ] دعم تقليل الحركة.
- [ ] قابلية قراءة ممتازة.
- [ ] لا يوجد ازدحام في الشبكة.

## التقنية
- [ ] لا توجد بيانات قرآنية Hard-coded في UI.
- [ ] قاعدة بيانات منفصلة.
- [ ] فهارس بحث.
- [ ] اختبارات.
- [ ] Error/Loading/Empty states.

## المراجعة الشرعية
- [ ] مراجعة أسماء الأنبياء والشخصيات.
- [ ] مراجعة ترتيب الأحداث.
- [ ] مراجعة الدروس المستنبطة.
- [ ] مراجعة التفاسير المختصرة.
- [ ] توثيق المصدر والترخيص.
